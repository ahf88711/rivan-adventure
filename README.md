# مغامرة ريفان

لعبة سيارات عربية مرِحة ومصممة أولًا للهواتف. يتحكم اللاعب في سيارة ريفان عبر ثلاثة مسارات، ويتفادى السيارات القادمة باستخدام زري **يسار** و**يمين**.

## المزايا

- واجهة عربية كاملة واتجاه RTL مع إبقاء التحكم الفيزيائي صحيحًا.
- ثلاثة مستويات سرعة: خفيف، متوسط، وسريع.
- توليد عادل للعوائق يترك مسارًا آمنًا دائمًا.
- تحكم لمسي كبير وسريع، مع دعم سهمي لوحة المفاتيح.
- أصوات مركبة بالكامل داخل المتصفح، من دون ملفات صوت محمية.
- نقاط وأفضل نتيجة محفوظة على الجهاز.
- دعم الشاشات العمودية والأفقية ومناطق الأمان في iPhone.
- تطبيق ويب تقدمي PWA قابل للتثبيت والعمل دون اتصال بعد أول زيارة.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث وpnpm.

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يعرضه Vite، وعادةً يكون:

`http://localhost:5173/rivan-adventure/`

## التحقق والإنتاج

```bash
pnpm lint
pnpm test
```

ينشئ أمر الاختبار نسخة إنتاج ثابتة ثم يتحقق من المسارات وواجهة الصفحة وملفات PWA الأساسية.

## النشر

تُنشر نسخة الإنتاج الثابتة من فرع `gh-pages` إلى:

`https://ahf88711.github.io/rivan-adventure/`

يبقى كود المصدر على الفرع `main`، بينما يحتوي `gh-pages` على ملفات البناء المنشورة فقط. إعداد `base` في Vite وجميع روابط الأيقونات وملفات PWA مضبوطة للعمل من المسار الفرعي الخاص بالمستودع.

## طريقة اللعب

1. اضغط **ابدأ**.
2. اختر السرعة المناسبة؛ المستوى الافتراضي هو **متوسط**.
3. اضغط **ابدأ اللعب** لتفعيل الصوت وبدء الرحلة.
4. استخدم **يسار** و**يمين** أو سهمي لوحة المفاتيح لتبديل المسار.

لا تتطلب اللعبة حسابًا أو خادمًا خلفيًا، وتُحفظ أفضل نتيجة محليًا فقط.
